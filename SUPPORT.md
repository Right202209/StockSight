# Support

StockSight is an open-source MVP and is maintained on a best-effort basis.

## Where to Ask

- For setup and runtime problems, check [Troubleshooting](docs/TROUBLESHOOTING.md)
  and search existing GitHub issues first.
- For a reproducible defect, open a bug issue with the environment, exact
  command, relevant logs, and steps to reproduce. Remove secrets and personal
  data before posting.
- For a feature or product suggestion, open a feature request that explains
  the user problem and the proposed behavior.
- For a security vulnerability, follow [SECURITY.md](SECURITY.md) and do not
  use a public issue.

## What to Include

Useful reports identify the StockSight commit, operating system, Python and
Node.js versions, deployment target, and whether the quote provider is
`yfinance` or `mock`. Include the smallest relevant log excerpt and a clear
expected-versus-actual description.

Support is provided for the current `main` branch. Third-party providers,
model endpoints, hosting platforms, and market-data availability remain
outside the project's control.
